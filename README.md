# PrimeCart

Sistema completo de e-commerce desenvolvido para estudo e demonstração de habilidades em desenvolvimento Full Stack.

## Demonstração

Frontend:
https://prime-cart-henna.vercel.app/auth

API:
https://projeto-e-commerce-9gmz.onrender.com

Swagger:
https://projeto-e-commerce-9gmz.onrender.com/api

---

## Funcionalidades

### Loja

- Listagem de produtos
- Busca de produtos
- Produtos por categoria
- Página de detalhes do produto
- Carrinho de compras
- Cadastro de usuários
- Login e autenticação
- Persistência do carrinho

### Painel Administrativo

- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Cadastro de categorias
- Edição de categorias
- Exclusão de categorias
- Gerenciamento de usuários
- Controle de estoque

---

## Tecnologias Utilizadas

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- Axios

### Backend

- NestJS
- TypeScript
- Prisma ORM
- JWT Authentication
- Swagger

### Banco de Dados

- PostgreSQL

### Deploy

- Frontend hospedado na Vercel
- Backend hospedado no Render

## Aprendizados

Durante o desenvolvimento deste projeto foram aplicados conceitos como:

- Arquitetura Full Stack
- Consumo de APIs REST
- Autenticação JWT
- Deploy em produção
- Integração Frontend + Backend
- Banco de dados relacional
- Gerenciamento de estado
- Responsividade
- Organização de código em camadas
