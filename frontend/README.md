# Frontend - PrimeCart

Frontend desenvolvido com Next.js para consumo da API do projeto E-commerce.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Axios
- Zustand

---

## Funcionalidades

- Home com produtos por categoria
- Busca de produtos
- Página de categoria
- Página de produto
- Carrinho de compras
- Login
- Cadastro de usuários
- Painel administrativo

---

## Instalação

Clone o projeto:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd frontend
```

Instale as dependências:

```bash
npm install
```

Execute em desenvolvimento:

```bash
npm run dev
```

## Integração com Backend

A aplicação consome uma API REST construída em NestJS.

Principais recursos utilizados:

- Produtos
- Categorias
- Usuários
- Autenticação JWT

---

## Deploy

O frontend está hospedado na Vercel.

Build:

```bash
npm run build
```

Produção:

```bash
npm start
```
